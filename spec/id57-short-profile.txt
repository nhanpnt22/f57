NOTICE
============================================================

As of ID57 Core API v0.2.0, this document is merged into
id57-core-api.txt and no longer stands on its own.

There is no separate ID57-SHORT profile, module, or API.
Short identifiers (previously described here as ID57-SHORT)
are produced with the standard ID57 Core API functions using
the existing informational length_enum values:

 ID57_LEN_23, ID57_LEN_29, ID57_LEN_32, ID57_LEN_47, ID57_LEN_70

 id57_generate(input_bytes, ID57_LEN_47)   // e.g. a short id
 id57_verify(input_bytes, id57_string, ID57_LEN_47)
 id57_range(ID57_LEN_47)
 id57_is_length(id57_string, ID57_LEN_47)

The collision model, required safety mechanisms, recommended
patterns, use cases, and prohibited usage that were specified
in this document now live in id57-core-api.txt, section 10
(SHORT-LENGTH USAGE).

Implementations MUST NOT expose separate ID57-SHORT-specific
function names, types, or defaults (e.g. id57s_generate,
ID57ShortLength, ID57S_DEFAULT). See id57-core-api.txt,
section 17 (REVISION NOTES, v0.2.0) for the full rationale.
