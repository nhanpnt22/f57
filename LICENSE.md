# License Notes

Canonical license text is in `LICENSE`.

## Summary

- License posture: restricted/internal (all rights reserved)
- Open-source use, redistribution, and derivative use are not permitted by default.
- Separate written permission is required for any external usage rights.

## Maintainer Guidance

If repository policy changes to an open-source license, update both:

1. `LICENSE` (canonical legal text)
2. `README.md` (license section)

Then re-run release assessments to ensure documentation consistency.
